## Archivo

```text
beatflow/js/ui/home.ui.js
```

La estructura de la Sesión 1 puede mantenerse porque `audius.api.js` normaliza los datos al mismo modelo visual.

Cambiar:

```text
BeatFlow · v0.1.0
```

por:

```text
BeatFlow · v0.2.0
```

Opcionalmente agregar:

```html
<p class="mt-1 text-sm text-zinc-500">
  Datos obtenidos desde Audius.
</p>
```

La UI continúa recibiendo objetos con:

```javascript
{
  id,
  title,
  artist,
  genre,
  duration,
  cover,
}
```
